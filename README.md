# 🔌 Arduino_Codes (아두이노 코드 및 하드웨어 제어 보관소)

아두이노(Arduino UNO Q / STM32 등) 및 센서/모듈 제어를 위한 스케치(`.ino`) 코드 저장소입니다.  
스피커, 부저, 통신 인터페이스(Bridge RPC, UART 시리얼) 연동 스케치가 포함되어 있습니다.

---

## 📂 프로젝트 구성

```text
Arduino_Codes/
├── arduino_q_buzzer/
│   └── arduino_q_buzzer.ino       # 피에조 부저 및 방송 알림 차임벨 연주 스케치
└── arduino_q_lm386/
    ├── arduino_q_lm386.ino        # LM386 앰프 스피커 본체용 스케치 (날씨/경보 알림)
    └── lm386_speaker_test.ino     # LM386 볼륨 및 출력 테스트용 스케치
```

---

## 📝 스케치별 상세 설명

### 1. `arduino_q_buzzer/arduino_q_buzzer.ino`
* **용도**: 아두이노 Q 온보드 부저(D8 핀)를 이용한 알림음 출력
* **주요 기능**:
  - TTS 음성 방송 시작 전 안내 차임벨("딩-동") 연주
  - 방송 중 온보드 LED 점등
  - Arduino RouterBridge RPC 및 내부 UART Serial 수신 지원

### 2. `arduino_q_lm386/lm386_speaker_test.ino`
* **용도**: LM386 앰프 모듈 및 8Ω 스피커 배선/볼륨 조절 테스트 스케치
* **주요 기능**:
  - 업로드 즉시 기본 음계(도-레-미-파) 테스트
  - 시리얼 모니터(115200 bps) 입력 테스트 (`1`: 비 경보음, `2`: 비 예보 멜로디, `3`: 맑음 팡파레)
  - 가변저항 볼륨 최적값 튜닝 지원

### 3. `arduino_q_lm386/arduino_q_lm386.ino`
* **용도**: LM386 앰프 스피커 메인 제어 스케치
* **주요 기능**:
  - 외부 기기/리눅스 MPU 명령에 따른 사운드 출력
  - 비 내림 긴급 경보(사이렌), 비 예보 알림(4음계 주의 멜로디), 맑음(팡파레) 등 다양한 패턴 지원

```text
             [ LM386 앰프 모듈 ]
        +--------------------------+
        |  [VCC]  ──► 아두이노 5V   |
        |  [GND]  ──► 아두이노 GND  |
        |  [ IN]  ──► 아두이노 D8   |
        |  [볼륨] ──► 파란색 가변저항 |
        | [스피커] ──► 8Ω 미니 스피커|
        +--------------------------+
```
